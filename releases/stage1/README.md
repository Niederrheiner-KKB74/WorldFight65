# WorldFight65 – Stage 1

The Rio beach arena and Tiago walking. Mount `WORLDFIGHT65.D81`, then `LOAD "WORLDFIGHT",8` and `RUN`.
Joystick port 2: walk; fire or F: turn round; X or RUN/STOP: back to BASIC. Needs attic RAM (MEGA65 R3+).
Notes and hardware checklist: `docs/stage1.md`.

Build (reproducible from the tagged sources):
```
python3 tools/build.py --kickass /path/to/KickAss65CE02-5.25.jar
```
